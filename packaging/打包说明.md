**`dist\DockStudio_Setup_1.1.0.exe`(约 4.3 MB,NSIS 在 Linux CI 上原生编译,已含 Eric Studio 版权/图标/许可)。**

- **安装位置**:`%LOCALAPPDATA%\EricStudio\DockStudio`(免管理员)。

## 1. 方案 A:conda-pack 绿色免安装(推荐)

在任何一台 **有网络** 的电脑上构建一次,产物即可拷到无网/无环境的电脑运行。

### Windows

```bat
:: 1) 安装 Miniconda (https://docs.conda.io 或清华镜像)
:: 2) 在项目根目录:
conda env create -f packaging/environment.yml
conda activate dockstudio
python -m dockstudio          :: 先确认能从源码启动(GUI 打开)

:: 3) 打包绿色目录:
packaging\condapack\build_win_condapack.bat
:: 产物: dist\DockStudioPortable\
```

把整个 `DockStudioPortable` 文件夹复制到目标 Windows 电脑,双击 `DockStudio.bat`
即可(不需要 Python、不需要安装 PyMOL/Vina)。首次运行会稍慢(解压缓存)。

> 为什么这样可以“包含 PyMOL/Vina 免安装”?conda-pack 会把整个 conda 环境
> (含 pymol-open-source、vina、meeko、openbabel、rdkit、plip 及它们的 .dll/.so)
> 打包成绿色目录,`DockStudio.bat` 直接用该目录内的 `pythonw.exe -m dockstudio`
> 启动,并把项目代码目录加入 `PYTHONPATH`。

### Linux / macOS

```bash
conda env create -f packaging/environment.yml
conda activate dockstudio
python -m dockstudio
# 绿色目录:
conda pack -n dockstudio -o DockStudioPortable.tar.gz
mkdir DockStudioPortable && tar -xzf DockStudioPortable.tar.gz -C DockStudioPortable
cp -r dockstudio DockStudioPortable/
# 启动:
cd DockStudioPortable && ./bin/python -m dockstudio   # 或写 .desktop / .sh
```

## 5. 科学默认参数(来自协议规格,可在 GUI ③ 参数中修改)

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| 初筛 exhaustiveness | 16 | 同一受体内所有配体保持一致,保证排序可比 |
| 精修 exhaustiveness | 32 | 每受体短名单 Top-12 再对接 |
| 每配体 pose | 9 | energy_range 4 kcal/mol |
| 最终 Top-K | 5 | 精修 mode-1 决定 |
| 随机种子 | crc32(`受体|配体`) & 0x7fffffff | 可复现,写入 result.json |
| 盒子 | 共晶配体质心 ± max(22 Å, 包络+12 Å),上限 32 Å | 见 ②结合位点 |

## 6. 协议中“必须询问的科学决策”如何落地

- **无共晶配体的位点**:GUI ②结合位点会要求你选择“手动中心/尺寸、残基中心、或盲对接(探索性)”;
  引擎不会自动猜测口袋。
- **链选择/生物单元**:GUI ①输入中“链/共晶…”可多选链。
- **质子化/立体化学**:按文档化简单规则(pH 7.4,羧基去质子化/脂肪胺质子化),
  报告中会列出每分子实际质子化说明;不调用 pKa 工具。
- **计算预算**:GUI ③参数可下调 exhaustiveness 以节省时间;报告中记录实际值。

## 8. 常见问题

- **PyMOL 打不开 `.pml` 报 UnicodeDecodeError**:我们的 `.pml` 全部纯 ASCII、
  引用本地 ASCII 文件名,规避了中文 Windows GBK 解码问题。请勿把输出目录放到
  含非 ASCII 字符路径时手工引用。
- **`vina` 无法导入**:确认 `python -c "import vina"` 在 **激活的环境中** 成功;
  打包版使用环境内 python。
- **回贴 RMSD > 2 Å**:提高 exhaustiveness 或检查质子化/盒子;报告如实说明,不掩盖。
