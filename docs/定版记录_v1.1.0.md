## 1. 变更摘要(相对 v1.0.0)

按用户要求完成的 8 项升级:

1. **GUI 现代化重设计**:改用 **ttkbootstrap** 现代主题(左侧“流程向导”导航 + 顶部操作栏 +
   卡片化步骤页 + 页脚状态),对标主流桌面/网页级软件体验;ttkbootstrap 缺失时自动回退
   标准 ttk,不阻断启动。
2. **输出目录文件夹选择器**:输出目录改为只读路径 + **系统文件夹选择器**(“浏览文件夹…”),
   无需手填路径。
3. **可选导出“分子对接准确性评估报告”**:新增 `core/accuracy.py`,在参数页勾选后于
   report 阶段生成 `reports/03_accuracy_assessment.md`、`reports/accuracy_assessment.csv`、
   `reports/accuracy_poses.csv`(逐受体 mode-1 RMSD、最低 RMSD 姿态、≤1.0 Å 高精度 /
   ≤2.0 Å 可接受 / >2.0 Å FAIL;无共晶配体受体如实标注不可评估)。
4. **分子对接流程科学严谨性全面核验与修复**(见下)。
5. **受体输入新增 mmCIF 格式**:`.cif/.mmcif` 经 gemmi 读取,内部转为与 PDB 相同的
   AtomRec,盘点/清洗/盒子/共晶坐标/RMSD 全程一致。
6. **全面优化改善**(见下)。
7. **新增查看 Help 文件功能**:顶部/菜单“帮助 → 帮助中心”,内置阅读器可查看
   用户手册、架构设计、定版记录、打包说明、README 等,并支持“在外部打开”;打包缺文档时
   显示内置快速帮助。
8. **参考全球顶尖软件设计的整体改良**:统一间距/排版/反馈、即时按钮态、结果页准确性
   评估直达按钮等。

## 2. 科学严谨性核验与修复清单(本次改动)

- **PDBQT 元素映射修复(影响回贴 RMSD)**:Vina 输出 PDBQT 行尾为 AutoDock 原子类型
  (A=芳香碳、NA/OA/SA=氢键受体、HD=氢供体…),旧解析会把 `A` 当“元素”导致芳香碳
  无法与晶体参考按元素匹配 → RMSD 系统性错误。已新增 `_element_of_pdbqt_atom`
  类型→元素映射。
- **自对接判定阈值统一**:PASS 由 `<2.0 Å` 统一为 **`≤2.0 Å`**,与准确性报告一致。
- **pH 简单规则显式阈值化**:原 `apply_ph_rules` 忽略 pH 参数、写死 7.4。现按目标 pH
  决定(羧酸 pH≥5 去质子;碱性胺 pH≤8.5 质子化),报告中披露目标 pH 与阈值,仍然不冒充
  pKa 预测。
- **盒内离子/辅因子移除如实披露**:清洗时会移除水/离子/配体;若被移除的离子/HET(含金属、
  辅因子、共晶配体)位于搜索盒内或 4 Å 邻域,写入 `CleanAction.warnings`,经
  `receptor.prepare_receptor` → pipeline → `01_methods_report.md` 逐条披露,杜绝静默省略。
- **共晶 CCD 参考质控指标修正**:原“CCD centroid dev”比较的是两个不相关坐标系(PDB 晶体
  坐标 vs CCD 模型坐标),作为误差指标无意义。改为 **重原子覆盖率(local vs CCD)** 与
  sanitize 状态作为质量指标,原质心偏移仅作信息字段。
- **Top-K 文件名随实际 K**:`final_top5.csv` 改名为 `final_top{K}.csv`(K=cfg.top_k),
  QC、报告、GUI 同步,避免 K≠5 时命名误导。
- **PyMOL 缺失时干净降级**:找不到 PyMOL 不再用裸 `python -cq` 产生误导性报错,而是
  明确记录“PyMOL not found, 3D render skipped”。
- **清洗/交互细节**:受体文件 `.cif` 清洗产物统一输出 PDB;`visualize`、`cofactor` 均走
  `parse_structure`;GUI 残基/盲对接盒子走 `parse_structure`。

## 3. 仍保留的已知说明(如实)

- 回贴 RMSD 用同元素原子贪心最近邻匹配,未做对称性修正(报告注明)。
- 质子化是简单规则而非 pKa 预测;手性/互变异构/关键可电离基团需人工复核。
- 无共晶配体受体全部结果标注探索性,准确性报告标注“不可评估”。
- PyMOL/PLIP 为可选;缺失时仅缺失对应图件/交互表,不影响主流程。
- Windows 安装包已在本仓库沙箱(Linux)用 **conda-forge NSIS 3.11** 直接编译产出
  (`dist/DockStudio_Setup_1.1.0.exe`)。重编译命令:
  `packaging/online_installer/build_online_installer.bat`(Windows)
  或 `makensis packaging/online_installer/DockStudio_online.nsi`(Linux/Windows)。
