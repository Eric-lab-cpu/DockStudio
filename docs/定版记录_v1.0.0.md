## 2. 功能范围(V1)

- 中文图形界面(GUI-only),五步:①输入 ②结合位点 ③参数 ④运行 ⑤结果
- 输入盘点 CSV(受体链/共晶配体/配体性质)
- 结构准备:Meeko 受体/配体 PDBQT;共晶配体 CCD 参考 SDF;盒子自动(共晶质心)/手动/残基/盲对接
- AutoDock Vina 对接:Windows 用内置 Vina CLI(1.2.7),Linux/mac 用 python-vina 或 CLI 双后端
- 断点续跑(done.flag)、时间片、每对 result.json/poses/best
- 初筛矩阵 → Top-12 精修 → Top-K(final_top5.csv / _final_top5.json)
- 共晶配体回贴(self-dock)重原子 RMSD 验证
- PLIP 相互作用(plip_summary.json / plip_interactions_all.csv)
- PyMOL 可视化:3D/composite/2D/TopK 拼接 PNG、ASCII `.pml`、`.pse`
- 方法/质量报告与自动 QC 交叉核对
- 一键打包脚本(conda-pack / PyInstaller / NSIS)

## 3. 本版本已修复的关键问题(存档)

1. Windows Sandbox(WDAGUtilityAccount)环境装配不稳定 → 改用“极简 conda 基底 + pip wheel”装配;检测沙盒并提示
2. conda qt-main 深路径超 260 字符 → PyMOL 安装用官方源 + 短缓存路径 + 重试,并提供 `Install_PyMOL.bat` 补装
3. micromamba/vina 缺 VC++ 运行库 → 内置 msvcp140.dll 等(vcrt)到对应目录
4. cmd 批处理括号解析导致闪退 → 重构为 goto 流程、echo 去括号
5. GUI 日志收到 dict 崩溃 → `_emit` 直接传字符串 + 防御式显示
6. 中文/OneDrive 输出目录导致 RDKit/meeko 写文件失败 → 引擎内部统一走 Windows 8.3 短路径
7. Vina CLI `log` 参数不存在 → 配置/直传均去除,输出自行落盘
8. 依赖解析(python=3.10+tk 8.6,去 prody/重复 openbabel)、错误可见性、后端诊断等

## 4. 已知说明(不作隐藏)

- PyMOL 为可选:若安装失败,DockStudio 仍可运行;仅 3D 光线渲染 PNG 缺失(2D/.pml 正常)
- prody 未随包安装(引擎不依赖,故不必要)
- 自对接 RMSD 通过与否取决于 exhaustiveness;低采样演示(RMSD≈5.5 Å)属预期
- 无共晶配体靶点结果一律标为探索性
