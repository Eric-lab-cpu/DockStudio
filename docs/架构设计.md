# DockStudio 架构设计

## 1. 设计原则

- **引擎与界面分离**:`dockstudio/core` 无任何 tkinter 依赖,可在无头环境被测试/编程调用;
  `dockstudio/gui` 只做参数收集与后台调度。这样 CI、冒烟、断点续跑都不需要显示器。
- **界面现代化(v1.1)**:`gui/app.py` 使用 ttkbootstrap 主题(左导航 + 顶部操作栏 +
  卡片化),ttkbootstrap 缺失时回退标准 ttk;输出目录通过系统文件夹选择器选择。
- **受体格式(v1.1)**:输入同时支持 **PDB(.pdb/.ent)** 与 **mmCIF(.cif/.mmcif)**
  (mmCIF 经 gemmi 读到与 PDB 相同的 AtomRec 表示,后续科学语义完全一致)。
- **可选准确性评估(v1.1)**:`RunConfig.run_accuracy_report` 开启后,report 阶段额外
  生成 `reports/03_accuracy_assessment.md` 与 CSV(基于自对接回贴,见 `accuracy.py`)。
- **数据即文档**:每个受体-配体对的对接目录写入 `result.json`(种子/盒子/affinities)、
  `poses.pdbqt`、`best.pdbqt`、`done.flag`(续跑标志)与 `error.json`。
- **可复现**:种子 = `crc32("<受体>|<配体>") & 0x7fffffff`;方法报告记录每一步真实参数。
- **绝不静默省略**:坏残基若靠近口袋会抛错询问;无共晶配体不会自动猜口袋;
  失败的 PLIP/可视化写入 error 字段。

## 2. 数据流

```
受体 PDB/mmCIF ─┐
                ├─► [inventory] 盘点 CSV(§4)
配体 SDF ────────┘        │
                         ▼
                  [box] 盒子决策(§5.4;共晶配体/手动/残基/盲)
                         │
                         ▼
[receptor.py] 清洗+PDBQT  [ligand.py] 质子化+PDBQT  [cofactor.py] 共晶SDF/PDBQT
        │              │                        │
        ▼              ▼                        ▼
[batch] screening(exh)  ─► done.flag 续跑        │
        │                                        │
        ▼                                        ▼
[ranking] 矩阵/短名单 ──► [batch] refine(exh32)  [selfdock] 回贴
        │                                        │
        ▼                                        ▼
 final_top{K}.csv/json                      RMSD 评估 ──► [accuracy] 准确性评估报告
        │                                        │          (v1.1, reports/03_*)
        ▼                                        ▼
[interactions] PLIP(Top-K 复合物) ──► plip_summary.json / interactions.csv
        │
        ▼
[visualize] PyMOL .png/.pml/.pse + 2D/composite/topK tile
        │
        ▼
[reports/qc] 方法报告 + 质量评估 + 准确性评估 + 一致性检查 + 目录树
```

## 3. 核心模块职责

| 模块 | 关键函数 | 说明 |
| --- | --- | --- |
| `structure.py` | `parse_structure/clean_receptor/inventory_pdb` | **PDB 与 mmCIF 双格式** 读取;清洗;盘点 |
| `receptor.py` | `prepare_receptor` | 清洗→meeko PDBQT;解析“坏残基”→距共晶配体>10 Å 才删 |
| `ligand.py` | `prepare_ligand_library/prepare_cocrystal_pdbqt` | 逐分子准备;pH 简单规则(**pH 阈值化**,非固定 7.4);每分子独立 meeko |
| `cofactor.py` | `write_cocrystal_ligand` | CCD 连接性 + 本地坐标;以**重原子覆盖率**与 sanitize 为质量指标 |
| `box.py` | `box_from_ligand/box_blind/box_auto_decision` | §5.4 决策树 |
| `docking.py` | `dock_pair` | Vina 封装;PDBQT **AutoDock 原子类型→元素** 映射 |
| `batch.py` | `run_docking_stage` | 阶段化批处理;时间片;续跑;错误收集 |
| `ranking.py` | `affinity_matrix/write_final_topk` | 初筛矩阵→精修→Top-K(`final_top{K}`) |
| `selfdock.py` | `evaluate_selfdock` | 同坐标系重原子 RMSD(≤2.0 Å PASS) |
| `accuracy.py` | `build_accuracy_report` | **对接准确性评估报告**(v1.1;`reports/03_*`, 每受体/每姿态) |
| `interactions.py` | `run_interactions_for_topk` | 复合物 PDB → PLIP → XML 解析 |
| `visualize.py` | `render_complex/composite_png/tile_pngs` | ASCII `.pml`;无头 PyMOL ray;缺 PyMOL 时干净降级 |
| `reports.py` | `write_methods_report/write_quality_report` | §12 两类报告;写入清洗提示与自对接一致项 |
| `qc.py` | `run_qc` | 矩阵/CSV/JSON/done.flag 自动核对(文件名随 Top-K) |
| `pipeline.py` | `run_project` | 阶段编排、状态持久化(`pipeline_state.json`)、安全停止 |

## 4. 关键科学决策的代码位置

| 决策 | 位置 | 行为 |
| --- | --- | --- |
| 链选择 | GUI ① / `InputReceptor.chains` | 只清洗所选链 |
| 无共晶配体位点 | `box_auto_decision` / pipeline `_auto_box_for` | 抛错要求人工决策,不盲猜 |
| 修饰残基(TPO/SEP…) | `structure.clean_receptor` | 记录转换;若在盒子 6 Å 内写警告 |
| 坏残基 | `receptor._classify_bad_residues` | 距共晶配体重原子>10 Å 才可删;否则报错询问 |
| 盒内离子/辅因子移除 | `structure.clean_receptor` | 落入/贴近搜索盒的被移除 HET/离子写**清洗提示**,报告如实披露 |
| PDBQT 元素 | `docking._element_of_pdbqt_atom` | AutoDock 类型(A/NA/OA/SA/HD…)→真实元素,保证 RMSD 元素匹配 |
| 质子化 | `ligand.apply_ph_rules` | 羧酸(pH≥5)→COO-,碱性胺(pH≤8.5)→+NH;附说明,不冒充 pKa 工具 |
| 自对接判定 | `selfdock` | mode-1 RMSD ≤ 2.0 Å PASS(与准确性报告阈值一致) |
| 准确性报告 | `accuracy.py` | 逐受体/逐姿态 RMSD;≤1 Å 高精度,≤2 Å 可接受,>2 Å FAIL |
| 名次在噪声内 | 报告中明示 | 差异<0.1 kcal/mol 不作强结论 |

## 6. 测试策略

- `tests/run_smoke.py`:无头端到端(4DFR),支持时间片+断点续跑,验证 §1–§12 全流程。
- 轻量单元测试(可选,不依赖 vina/PyMOL):格式化/盘点/CSV 一致性。
- QC 阶段每次运行自动交叉核对;交付清单见 README 与规格书 §12 末尾 checklist。
