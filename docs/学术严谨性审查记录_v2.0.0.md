## 2. 核对为「正确」的项(含证据)

- **RMSD 定义/坐标**:回贴 RMSD 为同一笛卡尔坐标系下、去氢重原子匹配(无重新叠加),
  与「self-docking redocking RMSD」惯例一致(`selfdock.py`/`accuracy.py`);贪心最近邻
  与对称性感知值分列,`symmetry_used`/`rmsd_method` 如实标注。
- **对称性等价类**:WL 颜色细化忽略键级/电荷,使羧酸/磷酸共振等价氧同类;仅类内匈牙利
  重排,不跨类交换(不会人为压低 RMSD);不可感知时退化贪心并披露。单轨道案例修复后
  (合成 O3 案例)对称 RMSD 确实优于贪心。
- **对接确定性**:种子 = `crc32('<rec>|<lig>') & 0x7fffffff` 写入 result.json;同参数可复现;
  PDBQT 元素解析(A/C→C、NA→N、OA→O…)正确,不会把 AutoDock 类型当元素破坏 RMSD 匹配。
- **能量解析**:`affinity_best = mode-1`(文件内 MODEL 1,最低能);初筛/精修矩阵与 final_top
  CSV 口径一致,QC 交叉验证矩阵 vs result.json。
- **AUC**:秩和(Mann-Whitney)带平均秩并列;手工复算含并列小样本 AUC=0.833=函数值;
  随机标签 AUC≈0.51(期望 0.5)。**EF1%/5%**=(top X% 内命中数/总活性)×(X%/100)⁻¹,教科书定义。
- **PLIP/可视化**:相互作用只用 PLIP 真实文本;PyMOL 缺失时 `ok=False` 并如实记日志,
  不产生假图件;`.pml` 全 ASCII。
- **报告诚实性**:方法/QC/准确性报告只列真实执行与真实参数;工具缺失时环境表如实显示
  `None`;未提供活性/诱饵时富集度明确「未启用/未提供,绝不自动生成」。

## 4. 残留说明(如实)

- GUI 无 tkinter,未在真实 Windows 实跑;仅语法编译 + 代码审查(本次修复不触碰 GUI 交互逻辑)。
- 质子化仍是**简单规则**(非 pKa 预测),报告已声明;多质子态/互变异构需人工复核。
- 富集度 EF/ROC 的「top X%」在标签子集内计算且按 `ceil(N·X%)` 取整,极小样本(如 3 个分子)
  的 EF 会放大——已在方法文字中提示以 AUC 为主、EF 为辅。
- 回贴 RMSD 在姿态与参考重原子数不一致时按「已匹配子集」计算并同时输出 `n_matched` 于
  `selfdock_summary.json`;极端缺失场景需人工注意(通常同一配体原子数一致)。
- 演示数据 4DFR/MTX 的共晶 SDF 之前受 A2 影响,现已用修复代码重新生成;
  历史(旧版)demo 输出中的 MTX 连接若被引用需以本次为准。
