### 第一轮(编码验证)发现并修复的 bug

1. `dockstudio/__main__.py`:headless run 的打印把 f-string 拆成两个相邻字面量 → Python 3.10
   语法错误。改为模块顶部导入 `__version__`,CLI 已可运行。
2. `core/symrmsd.py`:旧守卫 `len(orbits) > 1` 使「整个分子只有一个对称轨道」的合成案例不触发
   匈牙利重排 → 改为「存在非平凡轨道」即启用。
3. `core/vizhtml.py`:HTML 查看器计算了 3Dmol.js 加载 snippet 却从未写入页面(引用 `$3Dmol`
   但无 `<script src>`),查看器打开即失败 → 注入 `mol_snippet`;新增回归测试。

### 第二轮(学术严谨性审查)发现并修复的 bug(A1-A6)

详见 `docs/学术严谨性审查记录_v2.0.0.md`。要点:

1. **A1 羧基 pH 去质子化静默失效**(`ligand.apply_ph_rules`):SMARTS 取到羰基氧而非羟基氧,
   pH 7.4 下羧酸保持中性,与报告声称矛盾 → 已修复并加 `test_ligand_ph.py`。
2. **A2 CCD 键级解析全丢**(`cofactor.parse_ccd`):CCD 键级是大写码 `SING/DOUB/AROM`,
   按小写字典匹配导致全部回退单键(MTX 羧基/酰胺 C=O 全丢)→ 修复并加 `test_cofactor.py`;
   用修复代码重新生成 `examples/demo/ligand_library.sdf`。
3. **A3 富集度标签匹配失效**(`enrich.py`):带电 pH 形式与中性标签、SMILES 源原始串与
   规范串不匹配 → 统一「中性化规范 isomeric SMILES」作键。
4. **A4 富集度得分混用 refine/screening**:会系统性虚高 → 改为初筛单阶段口径;活性∩诱饵
   重叠按活性计并披露。
5. **A5 QC「精修 done.flag」恒真**:改为与按矩阵计算的期望短名单数比对。
6. **A6 盘点与准备配体命名不一致**(SDF `demo_mol1` vs `demo_1`;SMILES 无名字全撞 `mol`):
   统一到 `ligand.library_mol_name()`。

## 3. 已知风险 / 说明(如实)

- **GUI 未在真实 Windows 实跑**(沙箱无 tkinter)。代码经语法编译 + 审查,但界面交互、
  按钮触发的新阶段(enrich/html/zip)、About 版本等需要你本机双击确认。
- HTML 3D 查看器未内置 `3Dmol-min.js`,页面回退 CDN(需联网);如需完全离线,把
  `3Dmol-min.js` 放入 `dockstudio/resources/` 后重新生成。
- 新开关 `use_symmetry_rmsd=True`、`run_html_report=True` 默认开启(在文档中记录为「纯增量」);
  对称口径会改变准确性报告的主 RMSD 值(贪心值仍在对比列),旧工程读取后也会生成 HTML 报告——
  这是有意为之,请知悉。
- ROC/AUC 只反映「Vina 排序在给定体系下好不好」,缺活性/诱饵数据时如实跳过,绝不生成伪结果。
- Windows 安装包为**在线安装器**,首次运行需联网由 micromamba 装配 PyMOL/RDKit 等。

## 5. 建议你本机回归清单

1. 双击 `dist/DockStudio_Setup_2.0.0.exe` 安装并启动(GUI About 显示 v2.0.0)。
2. 导入一个旧 v1.1 工程跑一遍,确认能读 `config.json`、输出目录结构不变。
3. 在 ③ 参数勾选「富集度验证模式」并给活性/诱饵 SMILES 跑一遍,检查 ROC/AUC 是否写入报告。
4. 在 ⑤ 结果页打开「HTML 总报告」与「3D 查看器」,确认 3D 能渲染(首次需联网)。
5. 试用 SMILES/CSV 配体库与「并行任务数>1」。
6. 点击「打包导出 .zip」,确认压缩包含 config/结果/报告/environment.json。
