## 1. 变更摘要(相对 v1.1.0)

v2.0.0 按「桌面级可发表虚拟筛选工作台」定位交付,核心圈定为路线图 §6.3 的
#15/#16/#17/#18/#20/#23,并按用户确认把前置补丁 #1(对称性 RMSD)、#2(SMILES/CSV
输入)、#13(多核任务池)并入本次版本。**不引入** Fpocket / gnina / 多打分共识
(保持纯 Python/pip,安装包体积与科学边界可控)。

### 1.1 科学严谨性

1. **对称性感知 RMSD(#1)**:自对接与准确性报告的主口径从“同元素贪心最近邻”升级为
   “对称等价类感知”的 RMSD。等价类由参考分子拓扑图的 **Weisfeiler-Lehman 颜色细化**
   计算(忽略键级/电荷,使羧酸/磷酸等共振等价氧归为同类),同类内原子用匈牙利算法
   重排使 RMSD 最小;**贪心最近邻值保留为对比列**(`*_greedy*`)。对称性不可用(分子
   过大)时如实退回贪心并在 `rmsd_method`/`symmetry_used` 标注。涉及 `core/symrmsd.py`、
   `selfdock.py`、`accuracy.py` 与报告文本。单测含对称合成案例。
2. **ROC/AUC 富集度验证工作流(#16)**:`core/enrich.py`。仅当用户在 GUI ③启用
   “富集度验证模式”并给出**已知活性 + 诱饵**文件(SDF/SMILES/CSV)时运行;按规范
   (isomeric)SMILES 给已对接分子打标签,用真实 mode-1 Vina 亲和力(refine 优先,否则
   screening)计算 AUC(Mann-Whitney,平均秩处理并列)、EF1%/5%,输出 ROC 曲线(SVG)、
   ROC 点 CSV、逐分子 CSV、`enrichment_summary.json/.csv`。缺失数据/文件时如实跳过,
   **绝不自动生成活性或诱饵**。
3. **方法学披露升级**:报告/README/用户手册同步说明以上口径;新增的 v2.0 阶段均在
   报告留痕(对称性方法、并行参数、富集度方法学与数据来源)。

### 1.2 高通量与交互

4. **VS 规模吞吐 + 多核任务池(#13/#15)**:`core/batch.py` 增加 **ProcessPool 并行
   对接**(`n_workers>1`,每 worker 用 `cfg.cpu` 线程,保证结果与串行同参数一致)、
   **流式读取结果**(`iter_results`,避免 10 万级 result.json 全载内存)、按配体断点
   续跑、分批有界在飞任务;`run_summary.json` 记录各阶段真实 总数/成功/失败/耗时/吞吐。
5. **SMILES/CSV 配体批量输入(#2)**:`core/ligand.py`/`inventory.py` 支持 `.smi`/
   `.csv`(ETKDG+MMFF 生成 3D、逐分子失败记录、SMILES→来源留痕);GUI ①可添加。
6. **交互式 HTML 3D 查看器 + HTML 总报告(#17)**:`core/vizhtml.py`。每个 Top 复合物
   导出 `results/html_viewers/*.html`(3Dmol.js;口袋残基自动圈定 + PLIP 相互作用文本;
   不绘制几何猜想的“相互作用线”,如实披露);`reports/html/index.html` 为 md 总报告
   的姊妹件(目录、环境、Top-K、准确性、富集度、查看器链接)。内置 3Dmol.js 时完全
   离线;未内置时回退 CDN 并在页面注明。
7. **数据打包导出(#18)**:`core/project.py`。一键把整个输出目录打成带版本+时间戳的
   `.zip`(含源文件/结果/报告/CSV/JSON/HTML/environment.json);另有 `.dsproj`
   工程封装(向前兼容读取旧 `config.json`),headless CLI 可读取。
8. **headless CLI + 跨平台(#20)**:`python -m dockstudio run <config.json|.dsproj>`
   [--out …][--phases …][--time …];GUI-first 定位不变。新增 `packaging/cross/`
   (Linux/macOS conda-pack 绿色目录脚本 + 文档)与 `packaging/ci/release_all.sh`
   (三平台产物 + MD5 + Release 说明编排)。
9. **CITATION.cff(#23)**:仓库根新增机器可读引文元数据;README 增加“如何在论文引用
   DockStudio”;DOI 注册动作由作者在 Zenodo 完成(操作步骤写进 README/CITATION.cff)。

### 1.3 兼容性

- `RunConfig` 新增字段全部**默认关闭或纯增量**:`n_workers=1`、`run_enrichment=False`、
  `actives_path/decoys_path=""`、`use_symmetry_rmsd=True`、`run_html_report=True`。
- 既有 `config.json` 可被原样读取;旧 `final_top{K}.csv`、`docking/`、`refine/`、
  `reports/` 等文件名与目录结构不变(仅新增列/新增目录)。
- `selfdock_summary.csv`/`accuracy_assessment.csv` 新增贪心对比列与对称性列(列追加,
  旧列名保留在表头靠前位置)。

## 2. 仍保留的已知说明(如实)

- 质子化仍是文档化简单规则(非 pKa 预测);手性/互变异构/关键可电离基团需人工复核。
- 无共晶配体受体结果标注探索性、回贴验证标注“不可评估”。
- 对称等价类用颜色细化近似自同构轨道;对高度规则的对称图(罕见)可能把本不等价的
  原子并入同类,影响仅是把 RMSD 算得略宽松,报告披露该方法。
- ROC/AUC 是“这把 Vina 排序在该体系下好不好”的验证指标,不等于活性预测精度;
  若部分活性/诱饵未对接成功,报告给出标签流失计数并如实披露。
- HTML 查看器中的口袋残基由几何距离(6 Å)圈定,仅供交互查看;不构成实验结论。
- HTML 3D 查看器在本仓库未内置 `3Dmol-min.js` 本地副本,生成页面回退 CDN(需联网);如需完全
  离线,把 `3Dmol-min.js` 放到 `dockstudio/resources/` 后重新生成(页面会如实标注)。
- Windows 安装包已重建并给出 MD5(见 §6);**GUI 未在真实 Windows 实跑**(沙箱无 tkinter),
  需用户在本机双击安装并回归(见交付摘要建议清单)。

## 4. 测试记录(2026-09-08 Linux 沙箱实测)

沙箱环境:Linux + Python 3.10;rdkit 2026.03.6、meeko 0.8.0、vina 1.2.7(python 后端)、
gemmi 0.7.5、prody 2.6.1、plip 3.0.1。GUI 无 tkinter,仅语法编译 + 代码审查。

1. `python -m compileall -q dockstudio tests` → **通过**。
2. `python -m pytest tests -q` → **34 passed**(含新增 5 个测试文件:
   `test_symrmsd.py`/`test_enrich.py`/`test_smiles_input.py`/`test_project.py`/`test_vizhtml.py`)。
3. 无头端到端 smoke(4DFR demo,时间片断点续跑,`examples/demo`):
   - **旧配置** `python tests/run_smoke.py 140 --out /tmp/smoke_legacy --legacy` → 完成,
     `run_summary.json`:interrupted=false、enrichment=false、html_report="";旧文件结构不变。
   - **新配置** `python tests/run_smoke.py 140 --out /tmp/smoke_new --workers 2` → 完成;
     进程池 screen 3 配体 72.9 s、refine 3 配体 92.4 s;`reports/html/index.html` + 3 个
     `results/html_viewers/*.html` 生成。
   - selfdock(MTX 回贴,exh=10)两配置 mode1 RMSD≈8.7 Å(FAIL,低 exh 的预期现象,如实报告);
     新配置对称口径 mode1 8.726 Å vs 贪心对比列 8.754 Å(`symmetry_used=yes`)。
4. headless CLI `python -m dockstudio run /tmp/smoke_new/config.json --phases html`
   → **exit 0**,重新生成查看器与总报告。
5. Windows 安装包重建 + MD5:见 §6。

> **验证中发现并修复的 bug(均已含在以上通过结果中)**:
> - `dockstudio/__main__.py`:headless run 的打印语句把 f-string 拆成两个相邻字面量,Python 3.10
>   语法错误 → 改为在模块顶部导入 `__version__` 后单行格式化。
> - `core/symrmsd.py`:旧守卫 `len(orbits) > 1` 使「整个分子只有一个对称轨道」的合成案例不触发
>   匈牙利重排 → 改为「存在非平凡轨道」即启用,方法标注相应修正。
> - `core/vizhtml.py`:HTML 3D 查看器计算出了 3Dmol.js 加载 snippet 却从未写入页面,导致查看器
>   打开后引用未定义的 `$3Dmol` → 在 `_viewer_html` 中注入 `mol_snippet`;并新增
>   `tests/test_vizhtml.py` 回归测试(3 个)。
